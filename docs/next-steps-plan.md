## 执行方式选择

对于每个任务，可以选择：

**A. Subagent-Driven（推荐用于复杂任务）**
- 适合：班级成员一致性、数据备份自动化
- 优点：完整的计划和测试覆盖
- 缺点：需要更多 API 调用

**B. Direct Execution（推荐用于简单任务）**
- 适合：题库归属校验、N+1 查询修复
- 优点：快速执行
- 缺点：需要手动验证

**C. Plan-First（推荐用于不确定的任务）**
- 适合：日志系统、首次使用引导
- 优点：先对齐方案再执行
- 缺点：需要两轮交互
