# 管理后台运营工具使用指南

本文档介绍管理后台新增的运营工具功能。

## 功能概览

管理后台新增以下功能模块：
- 用户详情页面
- 用户删除功能
- 批量数据清理
- 系统公告管理
- 数据导出

## 1. 用户详情页面

**路径：** `/admin/users/{user_id}`

**功能：**
- 查看用户基本信息（用户名、角色、注册时间等）
- 查看学生学习统计（答题数、正确率、收藏数）
- 查看教师资源统计（创建的班级、题目、题库数量）
- 查看最近活动记录
- 执行管理操作（重置密码、禁用账号、删除用户）

**访问方式：**
在用户管理页面点击用户名即可进入详情页。

## 2. 用户删除功能

**路径：** `/admin/users/{user_id}/delete`

**功能：**
- 删除用户及其关联数据
- 级联删除策略：
  - 学生：删除答题记录、收藏、班级成员关系
  - 教师：如果创建了班级、题目或题库，需要先转移或删除这些资源
  - 管理员：不允许删除

**使用流程：**
1. 进入用户详情页
2. 点击"删除用户"按钮
3. 确认删除操作
4. 系统检查是否可以删除
5. 执行删除并记录审计日志

**注意事项：**
- 删除操作不可逆，请谨慎操作
- 教师如果创建了资源，需要先处理这些资源
- 所有删除操作都会记录审计日志

## 3. 批量数据清理

**路径：** `/admin/batch-cleanup`

**功能：**
提供三种批量清理类型：

### 3.1 测试账号清理
- 清理用户名包含"test"的账号
- 适用于清理测试环境的测试数据

### 3.2 过期游客清理
- 清理30天未登录的游客账号
- 自动清理不活跃的临时账号

### 3.3 无效数据清理
- 删除孤立的答题记录（关联的题目已删除）
- 删除无效的班级成员记录

**使用流程：**
1. 选择清理类型
2. 预览待清理数据
3. 确认后执行清理

## 4. 系统公告

**路径：** `/admin/announcements`

**功能：**
- 创建、编辑、删除公告
- 启用/禁用公告
- 设置公告类型（信息、警告、成功、错误）
- 设置目标角色（全部、学生、教师）
- 设置优先级和有效期

**公告显示：**
- 学生和教师首页自动显示相关公告
- 按优先级和创建时间排序
- 过期公告自动隐藏

## 5. 数据导出

**路径：** `/admin/data-export`

**导出类型：**

### 5.1 用户数据
- 导出所有用户基本信息
- 包含：ID、用户名、角色、班级、注册时间等

### 5.2 班级数据
- 导出所有班级信息
- 包含：班级名称、创建者、成员数、创建时间等

### 5.3 题目数据
- 导出所有题目内容
- 包含：题目、选项、答案、难度等

### 5.4 学习统计
- 导出所有学生学习数据
- 包含：答题数、正确率、收藏数等

**文件格式：**
- CSV格式，UTF-8编码（带BOM）
- 可在Excel中直接打开
- 文件名包含导出日期

## 安全说明

**权限控制：**
- 所有功能仅限管理员访问
- 非管理员访问返回403错误

**CSRF保护：**
- 所有POST请求需要CSRF令牌
- 防止跨站请求伪造攻击

**审计日志：**
- 所有关键操作记录审计日志
- 包含操作者、操作类型、目标资源、操作时间

**确认对话框：**
- 删除操作需要确认
- 批量清理需要勾选确认框

## 常见问题

**Q: 为什么不能删除某个教师？**
A: 该教师创建了班级、题目或题库。请先转移或删除这些资源。

**Q: 批量清理会删除哪些数据？**
A: 预览页面会显示所有待删除的数据，确认后才会执行。

**Q: 导出的CSV文件乱码怎么办？**
A: 文件使用UTF-8编码（带BOM），应该可以在Excel中正常打开。如果仍然乱码，请使用记事本打开并另存为ANSI编码。

**Q: 公告如何设置有效期？**
A: 创建公告时填写"过期时间"字段，留空表示永久有效。
