## 技术实现

### 页面结构
每个页面包含4个文件：
- `.js` - 页面逻辑和数据处理
- `.json` - 页面配置
- `.wxml` - 页面模板
- `.wxss` - 页面样式

### API 集成
所有页面已集成后端 API：
- `/api/v1/questions/random` - 随机题目
- `/api/v1/practice-records` - 答题记录
- `/api/v1/assignments` - 作业列表
- `/api/v1/assignments/{id}` - 作业详情
- `/api/v1/assignments/{id}/submit` - 提交作业
- `/api/v1/practice-records/mistakes` - 错题列表
- `/api/v1/users/me/stats` - 用户统计

### 工具函数使用
- `request.js` - 统一请求封装
- `auth.js` - 认证管理
- `storage.js` - 本地存储
- `util.js` - 通用工具
