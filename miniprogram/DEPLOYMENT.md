# 付刷小程序部署指南

## 一、前置准备

### 1.1 微信小程序账号

1. 访问 [微信公众平台](https://mp.weixin.qq.com/)
2. 注册小程序账号（需要企业或个人认证）
3. 获取 AppID（开发 - 开发管理 - 开发设置）

### 1.2 开发工具

1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 安装并登录

### 1.3 后端 API

确保后端 API 已部署并可访问：
- API 地址必须是 HTTPS
- 已配置 CORS 允许小程序域名
- JWT 认证正常工作

---

## 二、配置小程序

### 2.1 修改 AppID

编辑 `project.config.json`：

```json
{
  "appid": "你的小程序AppID"
}
```

### 2.2 配置 API 地址

编辑 `config.js`：

```javascript
const API_CONFIG = {
  production: {
    baseUrl: 'https://your-api-domain.com/api/v1',
    timeout: 10000
  }
};

const ENV = 'production';  // 改为 production
```

### 2.3 配置服务器域名

在微信公众平台配置合法域名：

1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. 开发 - 开发管理 - 开发设置 - 服务器域名
3. 添加以下域名：

**request 合法域名**：
```
https://your-api-domain.com
```

**注意**：
- 必须是 HTTPS
- 不能使用 IP 地址
- 不能带端口号（除非是 443）
- 域名需要备案（中国大陆）

---

##三、开发调试

### 3.1 导入项目

1. 打开微信开发者工具
2. 选择"小程序" - "导入项目"
3. 选择 `miniprogram` 目录
4. 填写项目名称和 AppID
5. 点击"导入"

### 3.2 开发环境配置

在开发者工具中：

1. **关闭域名校验**（仅开发时）
   - 详情 - 本地设置 - 不校验合法域名
   
2. **开启调试模式**
   - 详情 - 本地设置 - 打开调试

3. **配置代理**（如果需要）
   - 详情 - 本地设置 - 代理设置

### 3.3 真机调试

1. 点击工具栏"预览"按钮
2. 使用微信扫描二维码
3. 在手机上查看效果

**注意**：真机调试需要配置合法域名

## 六、上传发布

### 6.1 上传代码

1. 在开发者工具中点击"上传"
2. 填写版本号（如 1.0.0）
3. 填写项目备注
4. 点击"上传"

### 6.2 提交审核

1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. 版本管理 - 开发版本
3. 选择刚上传的版本，点击"提交审核"
4. 填写审核信息：
   - 功能页面：选择主要功能页面
   - 测试账号：提供测试账号和密码
   - 补充说明：说明小程序功能

### 6.3 审核注意事项

**常见审核失败原因**：

1. **服务类目不符**
   - 确保选择正确的服务类目（教育 - 在线教育）
   
2. **缺少必要资质**
   - 教育类小程序可能需要相关资质证明
   
3. **功能不完整**
   - 确保所有功能可用，无明显 bug
   
4. **用户隐私**
   - 需要隐私政策页面
   - 获取用户信息需要明确告知

5. **测试账号问题**
   - 提供的测试账号必须可用
   - 确保审核人员能完整体验功能

### 6.4 发布上线

1. 审核通过后，在"审核版本"中点击"发布"
2. 发布后用户即可搜索和使用

## 七、版本管理

### 7.1 版本号规范

采用语义化版本号：`主版本号.次版本号.修订号`

- **主版本号**：重大功能变更
- **次版本号**：新增功能
- **修订号**：bug 修复

示例：
- 1.0.0 - 首次发布
- 1.1.0 - 新增教师端功能
- 1.1.1 - 修复登录 bug

### 7.2 灰度发布

对于重大更新，建议使用灰度发布：

1. 在微信公众平台设置灰度比例（如 10%）
2. 观察用户反馈和数据
3. 逐步扩大灰度范围
4. 确认无问题后全量发布

## 九、常见问题

### 9.1 域名配置问题

**问题**：request:fail url not in domain list

**解决**：
1. 检查服务器域名配置是否正确
2. 确保 API 地址使用 HTTPS
3. 等待配置生效（可能需要几分钟）

### 9.2 登录失败

**问题**：微信登录返回错误

**解决**：
1. 检查 AppID 和 AppSecret 配置
2. 确保后端微信登录接口正常
3. 检查网络请求是否成功

### 9.3 图片不显示

**问题**：图片路径正确但不显示

**解决**：
1. 检查图片路径是否正确
2. 确保图片文件存在
3. 检查图片格式是否支持

### 9.4 真机调试问题

**问题**：真机上功能异常

**解决**：
1. 检查是否配置了合法域名
2. 查看真机调试日志
3. 确保后端 API 可访问

## 十、安全建议

1. **不要在代码中硬编码敏感信息**
   - AppSecret 应该在后端配置
   - 不要提交包含真实 AppID 的代码到公开仓库

2. **使用 HTTPS**
   - 所有 API 请求必须使用 HTTPS
   - 配置有效的 SSL 证书

3. **Token 安全**
   - Token 存储在本地，不要传输给第三方
   - 定期刷新 Token

4. **数据验证**
   - 前端验证用户输入
   - 后端必须再次验证
