# 图片资源说明

本目录用于存放小程序所需的图片资源。

## 必需图标

### 应用图标
- `logo.png` - 应用 Logo（200x200px）

### TabBar 图标（81x81px）
- `practice.png` - 刷题图标（未选中）
- `practice-active.png` - 刷题图标（选中）
- `assignment.png` - 作业图标（未选中）
- `assignment-active.png` - 作业图标（选中）
- `mistake.png` - 错题本图标（未选中）
- `mistake-active.png` - 错题本图标（选中）
- `profile.png` - 个人中心图标（未选中）
- `profile-active.png` - 个人中心图标（选中）

### 其他图标
- `empty.png` - 空状态图标（200x200px）
- `success.png` - 成功图标
- `error.png` - 错误图标

## 图标设计规范

1. **尺寸**：TabBar 图标建议 81x81px，其他图标根据实际需求
2. **格式**：PNG 格式，支持透明背景
3. **颜色**：未选中状态使用灰色（#999999），选中状态使用主题色（#1890ff）
4. **风格**：简洁、扁平化设计

## 临时方案

在正式图标准备好之前，可以：
1. 使用微信开发者工具的默认图标
2. 使用在线图标库（如 iconfont）
3. 使用纯色占位图

## 图标资源推荐

- [iconfont](https://www.iconfont.cn/) - 阿里巴巴矢量图标库
- [Flaticon](https://www.flaticon.com/) - 免费图标资源
- [IconPark](https://iconpark.oceanengine.com/) - 字节跳动图标库
