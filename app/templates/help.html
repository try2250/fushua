📖 帮助中心

{% if role == 'teacher' %}

👩‍🏫 教师帮助

1. 建班

进入「班级」页面，点击「创建班级」，填写班级名称后提交。创建成功后可获取邀请码，将邀请码分享给学生即可加入班级。

2. 导入题目

进入「导入」页面，上传 JSON 格式的题目文件。系统会自动解析并预览题目内容，确认无误后点击「确认导入」即可批量添加题目到题库。

3. 布置作业

进入「作业」页面，点击「创建作业」，选择目标班级、题目范围和截止时间，提交后学生会收到作业通知。可在作业详情页查看学生完成情况。

4. 查看统计

进入「统计」页面，可查看班级整体正确率、题目错误率排行、学生个人答题数据等。支持按科目、章节筛选，帮助精准定位教学薄弱点。

5. 处理学生忘记密码

进入「学生」管理页面，找到对应学生，点击「重置密码」按钮。系统会将该学生密码重置为默认密码，学生登录后可在设置中自行修改。

{% elif role == 'student' %}

👨‍🎓 学生帮助

1. 注册登录

点击首页「注册」按钮，填写用户名、密码和昵称完成注册。如果有班级邀请码，注册后可在个人页面输入邀请码加入班级。

2. 做题流程

进入「刷题」页面，系统会根据你的学习情况智能推荐题目。选择答案后点击提交，即可查看正确答案和解析。也可以通过「题库」页面按科目、章节浏览题目。

3. 查看错题和收藏

做错的题目会自动进入「错题本」，方便后续复习。做题时点击收藏按钮可将题目加入「收藏」列表。在错题本和收藏页面可以重新练习这些题目。

4. 学习计划

进入「计划」页面，可创建每日刷题计划，设定目标题数。系统会跟踪你的完成进度，帮助你养成持续学习的好习惯。
